# Third party provenance

This package is the ZUKU distribution carrier for the maintained Next2D Player fork. Renderer code, API classes and worker algorithms are the existing Next2D implementation; their namespace and source were not renamed.

Upstream: https://github.com/Next2D/Player ; fork: https://github.com/zukuapp/zukbox-player ; verified source commit: 21ab944f670249c0d7f89f2b9fd480318bf60e82 ; source package version: 3.11.0. The carrier version is independent from the source player version. MIT copyright notices are retained in LICENSE and below. Generated TypeScript declarations rewrite module addresses to package-local paths so consumers do not require file: workspace dependencies.

The ZUKU fork additionally falls back to the existing WebGL2 renderer when the browser exposes WebGPU but cannot supply an adapter or device. No upstream copyright notices were replaced.
